A API de Integração do Trajetto conecta o sistema da sua empresa à operação de entregas: você lê documentos, rotas e o histórico de eventos, cria entregas a partir do seu ERP e recebe, em tempo real, um webhook a cada mudança que importa.

É uma API REST em JSON sobre HTTPS, versionada no caminho: tudo o que está descrito aqui vive em `/integration/v1`, no endereço <BaseUrl />.

## O que dá para fazer

- **Ler entregas e rotas** da empresa dona da chave, com os três identificadores de cada documento: o id do Trajetto, o código do seu ERP e a chave da NF-e.
- **Criar entregas** a partir do seu sistema, com as mesmas regras do cadastro manual do painel.
- **Receber webhooks** quando uma rota é liberada, uma entrega é concluída, um canhoto é enviado e em outros momentos do catálogo de tópicos.
- **Consultar eventos** por polling, para quem está atrás de um firewall e não pode receber chamadas.

## Antes de começar

A API faz parte do módulo **Entregas**. As chaves e os webhooks são criados no painel, em **Integrações**, por quem tem acesso a essa tela. A chave identifica a empresa: nenhuma rota recebe o id da empresa como parâmetro, e uma chave nunca enxerga os dados de outra empresa.

## Referência e console

A [referência da API](/docs/referencia) é gerada a partir do documento OpenAPI que a própria API publica, então descreve exatamente o que ela responde: endpoints, parâmetros, corpos, respostas e erros, além de cada webhook. Para testar uma chamada com a sua chave, use o [console interativo](/docs/console).

## Suporte

Toda resposta traz o cabeçalho `x-request-id`. Quando algo não sair como esperado, envie esse valor ao suporte junto com o horário da chamada: é com ele que a chamada é encontrada nos registros.
